About Orkitt

We like software that is understandable, useful and easy to maintain. That means fewer mystery abstractions and more code a developer can actually own.

The website intentionally borrows the friendly commercial-software look of the early 2010s. The engineering underneath does not: the site is responsive, accessible and built with current Next.js.

Workshop principles

  • Build useful things
  • Keep code understandable
  • Make ownership easy
  • Prefer personality over generic startup polish
